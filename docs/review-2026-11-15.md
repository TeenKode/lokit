# Ревью Lokit — 15 ноября 2026

База: main `76f5fef`, дополнение изменений PR #38. Результат — v0.9.3.

## Охват

Проверен прикладной JavaScript: основной интерфейс и редактор, очередь,
субтитры и временные шкалы, медиаконвейер и резервные движки, загрузка
ArtCraft/PDFCraft/кодеков, Service Worker, аналитика, настройки и оформление.
Проверены сборка, упаковка, версия, PWA и GitHub Actions. Сопоставлены 24 ранее
открытых PR #9–#32: многие содержали отдельные части перечисленных исправлений.

Сторонние парсеры в `js/vendor` проверены через их вызовы и имеющиеся тесты
реальных контейнеров; это не независимый аудит каждой строки стороннего
парсера, WebAssembly или исходников ArtCraft. Раскладка и доступность покрываются
существующими браузерными сценариями; новый визуальный дизайн не вводится.

## Подтверждённые дефекты и результат

| Область | Дефект | Исправление |
|---|---|---|
| ArtCraft | После ошибки одного файла другие загрузки продолжались; отмена могла ждать поток | Общий сигнал остановки, закрытие потоков, сохранение первой причины ошибки и уже записанных файлов |

| Рендер | 0% кадрирования и 0 px размытия подменялись значениями по умолчанию | Ноль сохраняется в общем рендерере предпросмотра и экспорта |

## Проверки

Локально пройдены `npm test`, синтаксические проверки JavaScript/Python и
`git diff --check`. `npm test` включает существующие проверки медиаконвейера и новые сценарии:
Service Worker с недоступным кешем, ограниченное ожидание PWA, обновление и
отмена ArtCraft, повреждённые настройки/аналитика, пустая очередь, геометрия и
подписи шкал, субтитры, Windows-имена/даты ZIP и комплектность релиза.

Расширены браузерные проверки: очистка выбранного видео, открытие инструмента
при запрете localStorage, отсутствие внешних редакторов в пакетной очереди и
повторное сохранение PDFCraft без сети. Их результат подтверждается только
GitHub Actions для окончательного SHA, отдельно от результата предыдущего
коммита PR #38. Локальный запуск Chromium недоступен из-за ограничений среды.

## Ограничения проверки

Не измерены автономность, расход памяти и аппаратные кодеки на физических
Android/iPhone и слабых ПК. Синтетические тестовые контейнеры не доказывают
работу любых 4K/HDR/VFR и многогигабайтных файлов. Полный архив с оригинальными
редакторами собирается при публикации тега; в тестах упаковщика используются
маленькие фикстуры, а оригинальные релизы отдельно проверяются CI.

Изменения объединяют решения из PR #9–#32, но эти PR не закрыты и не слиты
автоматически. Их следует сопоставить с этим набором перед дальнейшим слиянием,
чтобы не возвращать старые варианты тестов и изменений поверх v0.9.3.
