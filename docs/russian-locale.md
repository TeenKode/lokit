# Русский интерфейс в Lokit: состояние 16 приложений

В Lokit собственные инструменты уже на русском языке. Для оригинальных
WASM-веб-сборок ArtCraft перевод меню не достигается HTML-переводчиком,
поскольку эти программы рисуют интерфейс на canvas. Lokit не изменяет
WASM и оригинальные файлы, а передаёт русский код языка в их штатные
настройки либо вызывает официальные команды управления.

## Наличие русских каталогов

| Редактор | Русский словарь | Включение в Lokit |
|---|---|---|
| PDFCraft | Есть | `ui.set {key:"language",value:"ru"}` через `?control` |
| PhotoCraft | Есть | `photocraft.preferences.interface.language = "ru"` в localStorage |
| VectorCraft | Есть | `?lang=ru`, команда `app.language {lang:"ru"}` |
| FilmCraft | Есть | `prefs.set {key:"general.interfaceLanguage",value:"ru"}` |
| LightCraft | Есть | `window.lightcraft.command("ui.set",JSON.stringify({language:"ru"}))`, с повтором до инициализации WASM |
| EffectCraft | Есть | `prefs.set {key:"general.language",value:"ru"}` |
| DesignCraft | Частичный | Нативное меню Preferences → General → Interface Language; часть текста остаётся английской |
| FigCraft | Есть | `pref.language {language:"ru"}` через `?control` |
| WordCraft | Есть | `wordcraft.ui.language = "ru"`, а также команда `ui.language {value:"ru"}` |
| CADCraft | Есть | `ui.language {lang:"ru"}` |
| GridCraft | Есть | `gridcraft.ui.language = "ru"`, а также `app.language.set {language:"ru"}` |
| Craft Anything | Есть | Ручной выбор Settings → Language; веб-сборка не предоставляет проверенного управляющего API |
| SoundCraft | **Нет** | Нельзя включить без разработки перевода и пересборки |
| DeckCraft | **Нет** | Нельзя включить без разработки перевода и пересборки |
| TextureCraft | **Нет** | Последняя проверенная ветка содержит 10 локалей без `ru` |
| MaterialCraft | **Нет** | В проверенном исходном коде только английский и арабский |

Для некоторых приложений переключение выполняется при загрузке
WebAssembly, и меню может оставаться английским до завершения
инициализации. Подключённый оригинальный редактор может допускать
сохранённый пользователем выбор, а переключение без документированного
API нельзя гарантировать программно. Там, где API нет, Lokit показывает
уведомление вместо ложного подтверждения перевода.

Проблема отсутствующих каталогов не решается заменой `lang="en"` на
`lang="ru"` в HTML, простым добавлением переводов JSON на страницу
или функциями браузерного машинного перевода: UI генерируется
самими WASM-модулями. Для полноценного русского интерфейса этих
четырёх редакторов нужны новые таблицы локализации и компиляция
исходного Rust-проекта. Отдельная лицензия на знаки ArtCraft
требует удалить исходные фирменные знаки из модифицированной версии
при распространении. Существующие официальные WASM остаются
неизменёнными.

## Реализация

Общий модуль `js/craft-language.js` содержит перечень доступных
локализаций, правила безопасного слияния языковой настройки в
`localStorage`, URL-параметры и документированные управляющие
методы. Он не стирает остальные пользовательские настройки;
некорректный JSON оставляет неизменённым. Для приложений без
русского каталога URL не обещает русскую локализацию. Тест
`tests/test-artcraft-language.mjs` проверяет эту матрицу и
механизм переключения.
