# Надёжность загрузки ArtCraft

Загрузчик сохраняет файлы редактора в браузере по мере скачивания. При ошибке
сети или нехватке места он останавливает остальные параллельные загрузки,
дожидается их остановки и показывает исходную причину ошибки. Уже сохранённые
файлы остаются доступными для повторной попытки.

Открытие редактора без ожидания полной офлайн-копии отменяет текущую подготовку:
активные потоки ответа закрываются, новые файлы не запрашиваются. Отмена не
показывается как успешное завершение автономной копии.

Некорректное бесконечное или NaN-значение параллелизма заменяется двумя
загрузчиками: 100% означает, что файлы действительно подготовлены.

Проверки: `node tests/test-artcraft.mjs` покрывает остановку соседнего потока
при ошибке Cache Storage, исходное сообщение о нехватке места, отмену во время
чтения и до запуска, повторную загрузку с использованием кеша и некорректный
параллелизм. `python tests/test-artcraft-browser.py` проверяет запуск и
перезагрузку без интернета в Chromium с небольшим тестовым редактором.
