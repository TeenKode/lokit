# Компоненты из предоставленной выгрузки

В папке `js/vendor/` находятся три автономных JavaScript-компонента, выделенных из архивной выгрузки, предоставленной владельцем проекта.

| Локальный файл | Имя в выгрузке | Использование |
|---|---|---|
| trim-timeline.js | assets/js-min/trim-timeline__761d65393d5b.js | интерактивная шкала обрезки, миниатюры и маркеры |
| waveform-preview.js | assets/js-min/waveform-preview__75279ca3ae04.js | вычисление амплитуды/пиков аудиосигнала |
| subtitle-serializer.js | assets/js/subtitle-serializer__feab94c1a520.js | экспорт SRT и WebVTT |

Правки адаптации: удалены строки `sourceMappingURL` (исходных `.map` в сборке нет); в шкале времени CSS перенесён в общую таблицу стилей для соблюдения CSP. Сетевые зависимости и сторонние API не используются.

В файлах выгрузки не было текстов лицензий. Общедоступность исходников сама по себе не устанавливает право на перепубликацию: перед дальнейшим распространением потребуется сверить лицензии/авторов исходных проектов.
