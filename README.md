# Lokit — инструменты, которые работают локально

24 браузерных инструмента для видео, аудио, извлечения кадров, записи экрана и субтитров.

## Визуальные редакторы

- **Видео:** плеер с клавишами управления, миниатюры кадров, шкала времени; для обрезки — интерактивные маркеры начала и конца с подсветкой сохраняемого фрагмента.
- **Эффекты:** живой предпросмотр поворота, отражения, цветового фильтра, размытия, подписи и кадрирования. Настройки рядом с просмотром влияют на экспорт.
- **Аудио:** предпросмотр исходного видео, локальное построение формы волны по запросу для файлов до 16 МБ при поддержке декодирования браузером.
- **Субтитры:** список реплик, редактирование текста и временных меток, добавление/удаление и предпросмотр; изменения попадают в экспорт.
- **Запись:** панель выбора источника, таймер и остановка записи.

В визуальном редакторе используются три JS-компонента из предоставленной пользователем выгрузки: `trim-timeline.js`, `waveform-preview.js`, `subtitle-serializer.js`. Их исходные файлы и происхождение описаны в `THIRD_PARTY_COMPONENTS.md`. Из этих компонентов убраны динамические вставки CSS и ссылка на исходную карту файлов, чтобы они работали без внешних запросов. Остальные части интерфейса разработаны для Lokit. При последующем публичном распространении следует проверить условия исходных лицензий компонентов.

## Аналитика и конфиденциальность

**Только личная статистика** (`analytics.html`) в localStorage браузера. История 1200 последних событий, графики 7/30/90 дней, экспорт/очистка. Файлы, названия, пути и ошибки не отправляются на сервер. Общая аналитика и её backend удалены.

## Публикация

GitHub Actions при push в `main` запускает Node/Python тесты и проверяет UI в Playwright Chromium. GitHub Pages публикует ветку `main` отдельно; публикация не блокируется при ошибках тестов.

- Сайт: https://teenkode.github.io/lokit/
- Личная аналитика: https://teenkode.github.io/lokit/analytics.html

Локальные проверки:

```bash
node tests/test-tools.mjs
node tests/test-media.mjs
node tests/test-analytics.mjs
node tests/test-editor.mjs
python tests/test-structure.py
# Требуется установленный Playwright Chromium:
python tests/test-browser.py
```

Видео экспортируется браузерными Canvas, Web Audio и MediaRecorder (обычно WebM в реальном времени). Поддержка кодеков зависит от браузера и устройства. Для записи экрана и камеры требуется HTTPS и разрешение пользователя. PWA кеширует всё необходимое после первой загрузки.

## Версия и улучшения

Текущая предварительная версия — **v0.3.0**. Плашка в шапке открывает страницу `about.html` с историей изменений. Номер версии задаётся в `js/version.js`; при релизе также обновляются `sw.js` и `about.html`.

Добавлены локальное избранное, проверка параметров и диапазонов обрезки, блокировка настроек во время экспорта, удаление устаревшего результата при правках и улучшенная клавиатурная навигация. Всё хранится в браузере пользователя.
