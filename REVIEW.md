# Lokit v0.6.0 — ревью пакетной обработки

Дата: 11 ноября 2026 года.

## Изменения

- Новая страница `batch.html` для общего списка заданий разных неинтерактивных инструментов.
- Один входной файл на задание, для `video-merge`, `split-screen`, `subtitle-merger` — пары в выбранном порядке.
- Последовательный исполнитель `js/batch-queue.js`, лимит 100 заданий, снимок параметров и файлов на момент добавления.
- Индикатор каждого задания с неопределённым состоянием, когда движок не сообщает процент. Общий прогресс считается по числу задач, завершённые ошибки/отмены учитываются как завершение работы очереди.
- Пауза после текущего задания, отмена ожидающих/активного, повтор ошибок, очистка завершённых и сохранение по одному файлу.
- `js/zip.js`: автономный ZIP32 STORE без внешних зависимостей, CRC32 через чтение Blob блоками, UTF-8 имена, обработка конфликтов, отмена, ограничение 4 ГБ.
- Результаты анализа метаданных в ZIP и отдельных загрузках сохраняются в JSON; входные файлы и результаты не сохраняются в браузерном хранилище.
- PWA кеш и версионирование обновлены; опубликованный ZIP-релиз включает новую страницу.

## Локальные проверки

`npm test` — PASS. Тесты `tests/test-batch.mjs` и `tests/test-zip.mjs` проверяют различные инструменты, паузу, отмену, повтор ошибок, сохранение параметров, ограничение очереди, двоичные файлы, UTF-8, одинаковые имена, CRC32 (Python zipfile) и отмену ZIP.

`tests/test-batch.py` добавлен в кросс-браузерную матрицу Chromium, Firefox, WebKit и мобильный Chromium. Проверяются четыре настоящие операции с субтитрами, скачивание ZIP, чтение содержимого и автономное открытие в Chromium.

## Ограничения

- Браузерная обработка последовательная; общий процент не равен проценту обработанных байт.
- В браузере без поддержки декодирования отдельных кодеков соответствующий файл получает ошибку, остальные задачи продолжаются.
- ZIP32 не поддерживает архивы размером более 4 ГБ; для более крупных результатов используйте отдельные скачивания.
- Список заданий и данные файлов не переживают обновление страницы. Это сознательное ограничение ради приватности и памяти.
- На локальном Chromium в этом окружении действует `ERR_BLOCKED_BY_ADMINISTRATOR` для localhost. Сквозное тестирование выполняется в GitHub Actions.
