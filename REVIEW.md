# Lokit v0.8.0 — визуальный редактор и точность монтажа

Дата: 11 ноября 2026 года.

## Исправления и нововведения

- Добавлена точная временная шкала с масштабом 1×–32×, перемещением по диапазону, интерактивным курсором и шестью делениями времени.
- Границы редактируются в миллисекундах и синхронизируются с `start` / `end` в форме экспорта. Исходная шкала с ключевыми кадрами и визуальная подсветка отрезка сохранены.
- Шаг на кадр основан на вручную выбранной частоте 24–60 FPS; VFR не выдаётся за точное покадровое позиционирование.
- Для видео и субтитров добавлена ограниченная история правок Undo/Redo. Перемещение маркеров группируется во времени; новые действия после Undo удаляют ветку Redo.
- Некорректные временные границы не записываются в историю. Устранён сброс полей точных таймкодов при вводе: общие обработчики формы игнорируют события редактирования внутри точной шкалы.
- Добавлены горячие клавиши видеоредактора без перехвата ввода в текстовых полях.
- Обновлены справка, версия, кеш PWA, контроль существования ассетов и тесты.

## Проверки

- `npm test`: тесты 24 инструментов, модуля истории, геометрии шкалы, точности таймкодов, старых медиа-движков, пакетного ZIP, офлайн-ресурсов.
- `tests/test-browser.py`: новые проверки шкалы 2×, точных границ, отмены/повтора, шага по кадрам и истории субтитров в Playwright Chromium.
- `tests/test-formats.py`: независимая валидация контейнеров и дорожек через FFmpeg/FFprobe в GitHub Actions.
- Chromium, Firefox, WebKit и мобильная эмуляция: автоматические проверки в CI.

## Ограничения

- Миллисекундные параметры не обещают точности декодирования до одного кадра для любого формата. В быстром WebM режиме фактическое начало может совпадать только с ближайшим ключевым кадром; точная обрезка задействует перекодирование.
- При VFR без анализа исходных временных меток шаг по выбранной FPS является приблизительным.
- Синтетические форматы тестов не подтверждают работу со всеми роликами смартфонов и аппаратными ускорителями.
