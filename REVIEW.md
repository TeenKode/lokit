# Lokit v0.4.0 — ревью и проверка

Дата: 10 ноября 2026.

## Исправления

- Предпросмотр визуальных эффектов и экспорт делят один Canvas-рендерер. Переключатель показывает исходник и кадр результата.
- Синхронизация цикла видеообработки с `requestVideoFrameCallback` при поддержке браузером; fallback по таймеру.
- Параметры сохраняются по инструментам и восстанавливаются после перезагрузки; файлы и содержимое в настройки не записываются.
- Сброс сохранённых настроек, дополнительные сведения о поддерживаемых движках.
- Совместимость проверяется в CI для Chromium, Firefox, WebKit и мобильной эмуляции Chromium.
- Одна команда формирует новый номер версии, CHANGELOG, обновлённые HTML и PWA-кеш. Отдельный workflow создаёт архив для тега выпуска.

## Ограничения

- Полный WYSIWYG относится к одному кадру **до кодирования**. Звук, финальное сжатие и точные переходы между роликами не гарантированы визуальным предпросмотром. У склейки предпросматривается первый ролик; итоговый файл включает оба.
- Для ускоренного WebCodecs/FFmpeg экспорта пока нет проверенного контейнерного pipeline; функция не включена.
- Реальное тестирование на Android-оборудовании и всех возможных кодеках остаётся необходимым.
- GitHub Pages публикуется независимо от качества тестов: проверяйте успешные CI jobs после каждого push.
