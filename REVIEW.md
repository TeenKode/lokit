# Lokit v0.7.0 — ревью экспериментальных движков

Дата: 11 ноября 2026 года.

## Изменения

- Добавлены **необязательные** движки WebCodecs/Mediabunny и однопоточный FFmpeg/WASM (режимы «Конвертер» и «Сжатие»).
- По умолчанию остаётся проверенный офлайн-экспорт. Отмена, исключения, отсутствие кодека, сети или неисправный MP4 приводят к освобождению ресурсов и/или переходу на классический экспорт.
- Для WebCodecs проверяются число входных и выходных аудио/видеодорожек; при несовпадении результат не считается успешным.
- Для FFmpeg отдельный Worker завершается при отмене, ошибке или тайм-ауте; файл ограничен 90 МиБ. Многопоточный WASM не используется на GitHub Pages.
- Библиотеки загружаются только по явно указанным URL при выборе режима, кешируются локально для повторного открытия; пользовательские файлы никуда не передаются.
- Уточнены интерфейс, версия, документация и PWA-кеш.

## Проверки

- `npm test`: отказ в кодеке, fallback, проверка сохранения аудио, размер видео, тайм-аут и отмена Worker, ZIP, очередь, версия, сервис-воркер и остальные тесты.
- `python tests/test-formats.py`: контейнеры и кодеки; проводится на GitHub Actions.
- `python tests/test-experimental-browser.py`: принудительная блокировка CDN, после чего обычный экспорт должен завершиться.
- Chromium / Firefox / WebKit и мобильная эмуляция — проверяются в CI.

## Остаточные риски

- Нельзя считать поддержку WebCodecs гарантированной во всех браузерах и для всех кодеков.
- Глубокое тестирование реального FFmpeg/WASM в разных браузерах и на больших файлах отдельно от проверки fallback; дополнительные модули требуют первой загрузки через интернет и доступа к jsDelivr.
- Реальный Android/телевизоры, длинные ролики и аппаратные кодеры необходимо тестировать на устройствах.
